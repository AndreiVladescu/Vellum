# Translating Vellum

Every message the app shows lives in one file, `app/lib/l10n/app_en.arb`. A
language is one more file next to it. You do not need to touch any Dart code.

## Add a language

1. Copy the template and name the copy after the language code:

   ```sh
   cd app/lib/l10n
   cp app_en.arb app_fr.arb      # fr = French; use es, de, pt_BR, ...
   ```

2. In `app_fr.arb` change `"@@locale": "en"` to `"@@locale": "fr"`.
3. Translate the **values**. Leave the keys, the `{placeholders}` and the ICU
   syntax alone. You can delete the `"@key": { ... }` description blocks from your
   copy (they only exist in the English template, which is where translators read
   them: they say where a message appears and what its placeholders are).
4. Regenerate the Dart code from `app/`:

   ```sh
   flutter gen-l10n
   ```

   Only the `.arb` is committed: `app/lib/l10n/gen/` is git-ignored and is
   regenerated by `flutter run`, `flutter test` and `flutter build` anyway.
5. Check `app/lib/l10n/untranslated.json`. It lists, per language, the keys that
   exist in the English template but not in your file. A missing message is not
   an error: the app shows the English text for it. The file is `{}` when every
   language is complete.

## Try it

Run the app in your language without changing the system language:

```sh
cd app
LANGUAGE=fr LC_ALL=fr_FR.UTF-8 flutter run -d linux     # Linux
flutter run -d windows                                  # Windows: set the display language in Settings
```

On Android and macOS, set the device language and relaunch. The app resolves the
system locale against the files in `lib/l10n/`; a language without a file falls
back to English.

## Placeholders

A value in braces is filled in by the app. Keep it, and move it wherever your
language's word order needs it:

```json
"bookAdded": "“{title}” added to your shelf"
```

French: `"« {title} » a été ajouté à votre étagère"`.

## Plurals

Anything that counts is an ICU plural. English needs two forms (`=1` and
`other`); your language may need more (`zero`, `one`, `two`, `few`, `many`,
`other` — `other` is always required):

```json
"syncIssues": "{count, plural, =1{1 issue} other{{count} issues}}"
```

Polish, for example, would write
`{count, plural, one{{count} problem} few{{count} problemy} many{{count} problemów} other{{count} problemu}}`.

Some messages use `select` to pick a word by a value, e.g. `{unit, select,
chapter{chapter} other{page}}`. Translate the words inside the braces; leave the
value names (`chapter`, `other`) as they are.

## Adding a new message (for developers)

Add the key to `app_en.arb` with a `@key` entry (a `description`, and a `type` for
every placeholder), run `flutter gen-l10n`, and read it with
`L10n.of(context).theKey`. Name keys `<screen or feature><What it is>` in
camelCase (`detailRevertTitle`, `scanIsbnLabel`), one message per sentence, never
built by joining translated pieces. For text that lives on an enum or in a
service with no `BuildContext`, add a `labelOf(L10n l10n)` extension in
`app/lib/l10n/labels.dart` and call it from the widget.
